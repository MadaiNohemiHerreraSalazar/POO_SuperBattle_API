SuperBattle é um sistema de batalha entre super-hérois a partir da comparação de seus atributos. Cada batalha é separada em 6 atributos (Inteligencia, Força, Velocidade, Durabilidade, Poder e Combate), cada atributo é comparado com o seu igual, adicionando um ponto a cada vitória, em caso de empate em um atributo ninguém pontua. Após o combate de cada atributo, o vencedor é aquele com mais pontos, aquele que leva a vantagem.

api utilizada: https://akabab.github.io/superhero-api/
